AION Browser Support

AION Browser is a private web browser for video and music websites, with built-in content blocking, background audio, Picture in Picture and a sleep timer.

Help

  • A site looks broken? Tap ⋯ → Turn blocking off for this site.
  • Picture in Picture: start a video, then tap ⋯ → Picture in Picture.
  • Sleep timer: tap ⋯ → Settings → Sleep timer.
  • Bookmarks: tap ⋯ → Add Bookmark. Bookmarks appear on the start page.

Contact

Report a problem or ask a question: open an issue on GitHub.
